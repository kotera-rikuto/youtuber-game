## 2. ゲーム概要

### 2.1 コンセプト【確定】

プレイヤーがゼロからYouTuberを目指し、動画投稿、能力育成、体調管理などを行いながらチャンネル登録者数を増やすシミュレーションゲーム。

単に数字を増やすだけではなく、投稿スタイル、投稿頻度、動画企画、能力値、体力、炎上などを扱い、YouTuber活動を解像度高く疑似体験できる内容を目指す。

### 2.2 仮タイトル【確定】

『YouTuberになろう！（仮）』

### 2.3 主目的【確定】

- チャンネル登録者数を増やす
- 段階的な期限付き目標を達成する
- 最終的に登録者数1,000万人を達成する

### 2.4 UIの参考作品【確定】

Webシミュレーションゲーム『80億分の1』をUIの参考にする。

ただし、具体的な画面構成、配色、レイアウト、操作体系をそのまま踏襲するかは未確定。

## 3. ゲーム進行

### 3.1 時間単位【確定】

- ゲームは**1週間単位**で進行する
- 1年は52週間とする
- 日単位では進行しない
- プレイヤーが「次週に進む」操作を行うことで時間を進める
- 週を進めながら、能力とチャンネルを成長させる

### 3.2 週間行動システム【確定】

- 1週間に選択するメイン行動は必ず1つ
- メイン行動は「アルバイト」「休憩」「コラボ」「企業案件」の4種類
- コラボ・企業案件は解放条件を満たすまで選択できない
- クールダウン中の行動は選択できない
- 動画投稿、企画作成、能力強化、機材購入はメイン行動とは別に実行できる
- 病気による活動不能期間中は、通常の行動画面を操作できない

| メイン行動 | 確定している効果 |
|---|---|
| アルバイト | 10,000円を獲得し、体力を10消費する |
| 休憩 | 体力を50回復する |
| コラボ | 体力を10消費し、その週に投稿する全動画へ1.5倍のコラボ倍率を適用する |
| 企業案件 | 体力を5消費し、週開始時の登録者数に応じた報酬を獲得する |

- 休憩による回復は動画投稿の体力消費より先に適用する
- 回復後の体力は最大100に制限する
- 所持金が0円でもゲームオーバーにはならない
- 借金はできない

### 3.3 基本ゲームループ【確定部分】

1. その週に使用できる企画、能力ポイント、機材、解放済み行動を確認する
2. メイン行動を1つ選択する
3. 必要に応じて企画作成、能力強化、機材購入、投稿頻度変更を行う
4. 「次週に進む」で、設定された投稿頻度に従い動画を自動投稿する
5. 行動・投稿・イベント・炎上・健康状態・目標を順に処理する
6. 翌週またはステージクリア画面へ進む

## 4. ゲーム開始時の設定

### 4.1 動画投稿スタイル【確定】

ゲーム開始時に、プレイヤーはチャンネルの投稿スタイルを選ぶ。

| スタイル | 内容 |
|---|---|
| 王道系 | 商品紹介、ドッキリ動画など、一般的・王道的な動画を扱う |
| 特化系 | 野球、心霊など、ゲーム開始時に選んだ1つの専門分野に特化する |
| 炎上系 | 人に迷惑をかける行動を前面に出した、過激な迷惑系動画を扱う |
| アイドル系 | ビジュアル面を強みにし、メイク動画などを扱う |

- チャンネル種類はゲーム開始時に1回だけ選択する
- ゲーム開始後はチャンネル種類を変更できない

特化系を選択した場合は、同じ初期設定画面で次の10分野から1つを必ず選択する。

| 専門分野 | 管理コード |
|---|---|
| 野球 | `baseball` |
| サッカー | `soccer` |
| ゲーム攻略・検証 | `gaming` |
| PC・ガジェット | `pc_gadgets` |
| 科学・実験 | `science` |
| 歴史・文化 | `history_culture` |
| 心霊・オカルト | `occult` |
| 生き物・自然 | `nature` |
| 料理・食文化 | `food_culture` |
| アウトドア・サバイバル | `outdoor_survival` |

- 特化系では専門分野が未選択のままゲームを開始できない
- 王道系・炎上系・アイドル系では専門分野を選択せず、専門分野の値も保存しない
- 選択した専門分野は1つのゲーム人生に固定し、ゲーム開始後は変更できない
- 専門分野は初期版では企画プールだけを決定し、特化系の能力参照・再生数倍率・炎上確率は10分野で共通とする

### 4.2 初期プロフィール要素【確定】

- ゲーム開始時にチャンネル名を自由入力する
- チャンネル名はゲーム中いつでも変更できる
- 初期登録者数：0人
- 初期所持金：100,000円
- 初期体力：100
- 体力最大値：100
- 6能力の初期値：各10
- 初期能力ポイント：0
- 初期機材：なし
- 初期企画ストック：空
- 初期投稿頻度：週1本
- 機材がなくてもスマートフォンで動画投稿できる

年齢は将来候補として残すが、初期版の入力、ゲーム計算、DBには含めない。

### 4.3 登録不要の開始・セーブ【確定】

- プレイヤーに会員登録、メールアドレス、パスワード入力を要求しない
- 「始める」を押した時点で、裏側でSupabase匿名認証を実行する
- Cookieには匿名認証セッションだけを保存し、ゲームデータ本体は保存しない
- `localStorage`はセッションやセーブデータの保存に使用しない
- ゲームデータ本体はSupabase PostgreSQLへ保存し、匿名ユーザーIDによって所有権を判定する
- 同じブラウザではCookieからセッションを復元し、進行中ゲームを再開できる
- Cookieの削除、別ブラウザ、別端末からの復旧は初期版ではできない
- 初期版ではアカウント連携、引き継ぎコード、端末間同期を設けない
- 1匿名ユーザーにつき進行中のゲーム人生は最大1件とする
- 進行中に新しい人生を始める場合は、現在の人生を明示的に中断してから開始する
- 中断・クリア・ゲームオーバー済みの人生はDB上に保持するが、過去人生の一覧・閲覧機能は初期版に設けない
- 新しい人生は既存データを上書きせず、新しいゲーム人生として作成する

## 5. 動画企画と企画ストック

### 5.1 企画ストック方式【確定】

- プレイヤーは動画企画を毎週3件まで追加する
- 追加した企画はストックとして保持する
- 動画を投稿する際、ストックした企画をアイテムのように消費する
- 投稿頻度に合わせて、プレイヤーが並べ替えたストックの先頭から企画を使用して投稿する
- 投稿されなかった企画は翌週以降へ持ち越す
- 企画ストック上限は30件
- 企画作成は週のメイン行動を消費しない

### 5.2 プレイヤーによる自由記述【確定】

- プレイヤー自身が動画内容を自由記述できる
- 自由記述できる企画は**1週間につき3件まで**とする
- 企画タイトルは1〜100文字
- 追加後の企画は編集できない
- 投稿前の企画は自由に削除できる
- 企画を削除しても、その週の追加可能回数は回復しない
- プレイヤー作成企画は1回しか使用できない
- 企画追加時にAI評価を1回だけ実行し、評価点を保存する
- AI評価点はプレイヤーに表示しない
- AI評価失敗時も企画を追加し、60点として扱い、週間追加枠を1件消費する

### 5.3 ゲーム側の企画提案・おまかせ【確定】

- プレイヤーがゲーム側企画を事前に選んでストックへ追加する機能は設けない
- プレイヤー作成企画のストックが投稿本数に足りない場合、不足本数分だけゲーム側企画を自動選出し、その週に投稿する
- ゲーム側生成企画の再生数倍率は0.6倍、登録者転換率は2%とする

### 5.4 ゲーム側生成企画の再生保証【確定】

ゲーム側生成企画に最低再生数保証は設けない。ほかの動画と同じく基礎再生数と各倍率から計算する。

### 5.5 企画データの再利用【確定】

- 王道系・炎上系・アイドル系は各50件、特化系は10専門分野ごとに各50件を用意し、合計650件とする
- 王道系・炎上系・アイドル系では選択した投稿スタイルの50件、特化系では選択した専門分野の50件だけを抽選対象にする
- 対象となる50件を重複なしで一巡し、全件を使い終わった後はシャッフルして再利用する
- 最初のサイクルも50件をランダムに並べ替えて使用する
- 再シャッフル後の先頭が直前サイクルの最後と同じ企画になった場合は並べ直し、連続重複を避ける
- 各企画は管理用コード、対象チャンネル種類、特化系の場合だけ専門分野、企画タイトル、短い企画説明、有効状態を持つ
- サムネイル情報とAI評価点は持たない
- 固定倍率0.6と登録者転換率2%は企画ごとではなく、バージョン付き共通ルールとして管理する
- 長期間かつ高頻度の投稿で必要企画数が過大になることを防ぐ目的

### 5.6 今回の自動生成企画データ【確定】

- 王道系50件、炎上系50件、アイドル系50件を作成済み
- 特化系は10専門分野ごとに各50件、合計500件を作成済み
- 全チャンネルを合わせたゲーム側企画は650件とし、旧仕様の合計200件は廃止する
- 企画作成・レビュー時の正本は `data/system-ideas/*.json` とする
- 特化系の正本は `data/system-ideas/specialized/*.json` とし、`specialtyCode` で専門分野を識別する
- JSONはDBスキーマ実装前の中間成果物であり、ゲーム実行時のデータソースには使用しない
- 後続セッションでJSONを入力とする冪等なseed処理を実装し、`system_idea_templates` と `rule_set_system_ideas` へ投入する
- ゲーム実行時はRepositoryを通してSupabase PostgreSQLだけを参照する

## 6. 動画投稿

### 6.1 投稿頻度の基本設計【確定】

- 投稿頻度が高いほど成長に有利になる
- 投稿頻度が高いほど体力が減る
- 成長と体力消費のトレードオフを作る
- 毎日投稿は伸びやすい一方で弊害を持つ

### 6.2 投稿頻度の選択肢【確定】

| 投稿頻度 | 再生数倍率 | 週間体力消費 |
|---|---:|---:|
| 週1本 | 1.2倍 | -3 |
| 週3本 | 1.0倍 | -8 |
| 週7本 | 0.8倍 | -25 |

プレイヤーが設定した投稿本数に従い、「次週に進む」際に企画ストックの先頭から自動投稿する。

- 投稿頻度はいつでも変更でき、次に変更するまで維持する
- 次週進行時点で選択されている投稿頻度をその週へ適用する
- 体力消費は週間合計であり、動画1本ごとの消費ではない
- アルバイト、休憩、コラボ、企業案件を選択した週も動画を投稿する
- 病気による活動不能期間中だけは通常の動画投稿を行わない

### 6.3 投稿数と結果の関係【確定】

- 投稿頻度は、その週に投稿するすべての動画の再生数倍率と体力消費へ影響する
- 再生数倍率は、週1本が1.2倍、週3本が1.0倍、週7本が0.8倍
- 投稿本数が多いほど1本あたりの倍率は下がるが、週間総再生数を増やせる可能性がある

### 6.4 AI企画評価【確定】

- プレイヤーが入力した動画企画をAIが0〜100点で評価する
- 評価観点は、企画の新規性・魅力・チャンネル種類との適合性とする
- 評価は企画追加時に1回だけ行い、投稿時には再評価しない
- AI評価点に応じて再生数倍率と登録者転換率を決める
- AI評価に失敗した場合は60点として扱う
- ゲーム側の自動生成企画には固定の再生数倍率と登録者転換率を適用する
- ゲーム側の自動生成企画にはAI評価を使用しない
- AIは再生数、登録者数、ランダムイベントを直接決定しない
- 評価点から倍率・転換率への対応はプログラム側で管理する

## 7. 再生数

### 7.1 基礎再生数【確定】

- 動画1本ごとに、0〜100,000回の一様ランダムな整数から基礎再生数を決める
- 基礎再生数へ7種類の倍率を掛け、動画1本の再生数を算出する

### 7.2 登録者数による倍率【確定】

登録者数が10万人増えるごとに、倍率を0.5ずつ上昇させる。

```text
登録者倍率 = 1.0 + floor(登録者数 ÷ 100,000) × 0.5
```

例：

- 0〜99,999人：1.0倍
- 100,000〜199,999人：1.5倍
- 200,000〜299,999人：2.0倍
- 300,000〜399,999人：2.5倍
- 500,000人：3.5倍
- 1,000,000人：6.0倍

### 7.3 能力値による倍率【確定】

投稿スタイルごとに指定された2つの能力値の平均を使用する。

| 投稿スタイル | 使用する能力値 |
|---|---|
| 王道系 | 企画力・トーク力 |
| 特化系 | 専門知識・編集力 |
| 炎上系 | トーク力・企画力 |
| アイドル系 | ビジュアル・撮影技術 |

```text
能力倍率 = 1.0 + (能力平均値 - 10) ÷ 100
```

- 能力平均10：1.0倍
- 能力平均50：1.4倍
- 能力平均100：1.9倍

### 7.4 AI企画評価による倍率【確定】

| AI評価点 | 再生数倍率 | 登録者転換率 |
|---|---:|---:|
| 0〜39点 | 0.5倍 | 1% |
| 40〜59点 | 0.8倍 | 2% |
| 60〜79点 | 1.0倍 | 3% |
| 80〜89点 | 1.3倍 | 4% |
| 90〜100点 | 1.7倍 | 5% |
| 自動生成企画 | 0.6倍 | 2% |

AI評価に失敗した場合は60点として扱う。

### 7.5 投稿頻度による倍率【確定】

- 週1本：1.2倍
- 週3本：1.0倍
- 週7本：0.8倍

この倍率は、その週に投稿するすべての動画へ適用する。

### 7.6 チャンネル種類による倍率【確定】

- 王道系：1.0倍
- 特化系：1.0倍
- 炎上系：1.5倍
- アイドル系：1.0倍

### 7.7 機材による倍率【確定】

カメラ、マイク、編集PCの3種類について、機材レベルごとの補正率を加算する。

- 機材なし：+0%
- 初級：+5%
- 中級：+10%
- 上級：+15%

```text
機材倍率 = 1.0 + カメラ補正 + マイク補正 + 編集PC補正
```

例：上級カメラ、中級マイク、初級編集PCの場合は、15% + 10% + 5% = 30%なので1.3倍。最大倍率は1.45倍。

### 7.8 コラボによる倍率【確定】

- コラボを実施した週：1.5倍
- コラボを実施していない週：1.0倍

この倍率は、その週に投稿するすべての動画へ適用する。

### 7.9 ランダムイベントによる追加補正【確定】

通常の動画別再生数を合計した後、ランダムイベントによって週間総再生数を補正する場合がある。

- ランダムイベントは1週間に1回判定する
- 発生確率は合計10%とする
- 良いイベントは5%、悪いイベントは5%とする
- 炎上判定とは独立しているため、同じ週に両方が発生する場合がある

良いイベントが発生した場合は、次の3種類からそれぞれ3分の1の確率で選ぶ。

| イベント | 効果 |
|---|---|
| おすすめに掲載 | 週間総再生数を2.0倍 |
| 有名人に紹介される | 登録者数を5,000人増加 |
| 臨時ボーナス | 所持金を50,000円増加 |

悪いイベントが発生した場合も、次の3種類からそれぞれ3分の1の確率で選ぶ。

| イベント | 効果 |
|---|---|
| 動画が不評 | 週間総再生数を0.5倍 |
| 機材トラブル | 所持金を30,000円減少。機材は失われない |
| SNSで批判される | 登録者数を3%減少 |

機材トラブル後の所持金は `max(0, 変更前所持金 - 30,000)` とし、借金にはならない。登録者数の割合減少で発生した小数点以下は切り捨てる。1週間に発生する週間ランダムイベントは最大1つとする。

イベントによる再生数の変化は、登録者増加数と広告収益にも反映する。

### 7.10 最終的な計算方法【確定】

動画1本のイベント補正前再生数は、次の式で計算する。

```text
基礎再生数
× 登録者倍率
× 能力倍率
× AI企画評価倍率
× 投稿頻度倍率
× チャンネル倍率
× 機材倍率
× コラボ倍率
```

すべての倍率を掛け終わった後、動画ごとに小数点以下を切り捨てる。各動画の再生数を合計してイベント前週間総再生数を算出する。

再生数イベントが発生した場合、正式なイベント後週間総再生数を次で求める。

```text
イベント後週間総再生数 = floor(イベント前週間総再生数 × イベント倍率)
```

イベント後週間総再生数は、イベント前の各動画の再生数比率に応じて各動画へ比例配分する。各動画の配分値を一度切り捨て、週間総再生数との差分を配分時の小数部分が大きい動画から1回ずつ加算する。小数部分が同率なら週内の投稿順が早い動画を優先する。これにより、動画別最終再生数の合計と週間総再生数を必ず一致させる。

登録者増加数は、イベント補正後の動画別再生数に各動画の登録者転換率を掛け、動画ごとに小数点以下を切り捨ててから合計する。広告収益は、イベント補正後の週間総再生数に0.2円を掛け、週単位で小数点以下を切り捨てる。

炎上は再生数に直接影響しない。炎上時は登録者数を5%減少させ、体力を20減少させる。

## 8. 登録者数と目標

### 8.1 ステージ目標【確定】

ステージは全部で5つとし、各ステージの制限時間は156週間（3年間）とする。

| ステージ | 目標登録者数 | 制限時間 |
|---:|---:|---:|
| 1 | 100,000人 | 156週間 |
| 2 | 500,000人 | 156週間 |
| 3 | 1,000,000人 | 156週間 |
| 4 | 3,000,000人 | 156週間 |
| 5 | 10,000,000人 | 156週間 |

ステージ5の達成を最終クリア条件とする。

### 8.2 ステージ移行【確定】

- ゲーム開始時の処理対象は第1週とし、「次週に進む」で第1週を確定した後、処理対象を第2週へ進める
- ステージ1の期限は第156週を含み、第156週の結果で達成すればクリア、未達なら期限切れとする
- 第N週に目標を達成した場合、次ステージで最初にプレイする週は第N+1週、期限は第N+156週とする
- 例として第100週に達成した場合、次ステージのプレイ期間は第101〜256週の156週間とする
- 登録者数、所持金、体力、能力値、機材、企画ストックなどをすべて引き継ぐ
- ゲーム開始からの累計経過週数・年数はリセットしない
- 制限時間の最終週に目標を達成した場合もクリアとする
- 目標達成時はステージクリア画面を表示し、「次のステージへ進む」で移行する
- ステージ判定は、その週の行動、投稿、ランダムイベント、炎上、健康状態などすべての処理後に行う
- 体力0または炎上3回のゲームオーバーが成立した場合、同じ週に目標登録者数を満たしていてもゲームオーバーを優先する

### 8.3 最終クリア【確定】

- 最終ステージクリア時に、登録者数、累計再生数、所持金、経過年数、炎上回数などを表示する
- 初期版にエンドレスモードは設けない
- クリア後は最初から新しいゲームを開始する

## 9. 能力育成

### 9.1 能力値【確定】

プレイヤーキャラクターには、0〜100の範囲で育成可能な次の能力値を設ける。

- 企画力
- トーク力
- 専門知識
- 編集力
- ビジュアル
- 撮影技術

ゲーム開始時の各能力値は10、最大値は100とする。動画再生数には、投稿スタイルごとに指定された2能力の平均値を使用する。

### 9.2 能力強化の操作【確定】

- 画面上部に現在使用可能な能力ポイントを表示する
- 「能力を伸ばす」操作を選ぶと、保有ポイントを能力値へ割り振れる
- 割り振り可能な数値だけがプレイヤーに与えられ、その範囲で自由に配分する
- 能力強化そのものでは体力を消費しない
- 能力強化は週のメイン行動を消費しない

| 投稿頻度 | 正常に投稿できた週の獲得能力ポイント |
|---|---:|
| 週1本 | 3ポイント |
| 週3本 | 7ポイント |
| 週7本 | 15ポイント |

- 獲得ポイントは翌週から使用できる
- 能力ポイントは累積しない
- 翌週に使わなかったポイントは、その次の週への進行時に失効し、新しい獲得ポイントへ置き換える
- 活動不能中は獲得・使用できないが、既存の未使用ポイントは保持する
- 復帰後、最初の通常週が終わると未使用ポイントは失効する
- 一度確定した能力ポイントの配分は振り直せない

### 9.3 機材【確定部分】

次の3種類の機材を扱う。

- カメラ
- マイク
- 編集PC

各機材は「なし・初級・中級・上級」のいずれかのレベルを持つ。

| 機材 | 初級 | 中級 | 上級 |
|---|---:|---:|---:|
| カメラ | 30,000円 | 150,000円 | 500,000円 |
| マイク | 5,000円 | 30,000円 | 100,000円 |
| 編集PC | 50,000円 | 200,000円 | 500,000円 |

- 1種類につき1ランクだけ保有できる
- 上位機材を購入すると下位機材と置き換わり、同じ機材の補正は重複しない
- 初級は+5%、中級は+10%、上級は+15%
- 3種類の補正率を加算し、すべて上級の場合は1.45倍
- 機材購入は週のメイン行動を消費しない
- 所持金が不足する機材は購入できず、借金はできない
- 機材なしでもスマートフォンで投稿できる
- 機材故障イベントが発生しても、所有機材自体は失われない

## 10. 体力・休憩・健康状態

### 10.1 体力【確定】

- プレイヤーには体力パラメータがある
- 初期値・最大値は100
- 投稿頻度による週間消費は、週1本が3、週3本が8、週7本が25
- アルバイトは体力を10消費する
- 能力ポイントの割り振りでは体力は減らない

### 10.2 休憩【確定】

- 行動として休憩を選べる
- 休憩では体力を50回復する
- 休憩回復を動画投稿の体力消費より先に適用し、100を上限とする

### 10.3 体力低下によるリスク【確定】

- 病気・怪我は、メイン行動、動画投稿、炎上などによる体力変化をすべて反映した後の残り体力で週1回判定する

| 判定時の体力 | 発生確率 | 活動不能期間 |
|---:|---:|---:|
| 50〜100 | 0% | なし |
| 30〜49 | 5% | 1〜2週間 |
| 10〜29 | 15% | 3〜6週間 |
| 1〜9 | 30% | 8〜12週間 |
| 0以下 | 判定しない | 即ゲームオーバー |

- 発生時の活動不能期間は、該当範囲内の整数から均等確率で抽選し、その時点で確定する
- 初期版では病気と怪我による効果を分けず、共通の「体調不良」として扱う
- 初期版では病院、薬、支払いなどによる治療・期間短縮を設けない

### 10.4 活動不能中の操作【確定】

- 体調不良の判定が発生した週の結果は通常どおり確定し、翌週から活動不能にする
- 活動不能期間中は「次週に進む」以外の操作を無効化する
- 動画投稿、アルバイト、休憩、コラボ、企業案件、企画作成、機材購入、能力強化は実行できない
- 活動不能週は動画投稿、週間ランダムイベント、炎上判定、健康状態の再抽選、能力ポイント獲得を行わない
- 活動不能週を1週間進めるごとに体力を10回復し、最大100とする
- 既存の未使用能力ポイントは活動不能中に失効させず保持する
- 活動不能期間もステージの制限時間に含める
- 活動不能週も1週分の回復結果を確定してからステージ期限を判定し、期限最終週で未達ならゲームオーバーにする
- 画面内に「復帰まで残り何週」を表示する

例として第10週の終了時に2週間の体調不良が発生した場合、第11週と第12週が活動不能となり、第13週から通常操作へ復帰する。

## 11. 炎上系スタイルと炎上

### 11.1 炎上系の特徴【確定】

- 炎上系の動画企画は、他人や周囲へ迷惑をかける過激な「迷惑系動画」を中心とする
- 批評、商品レビュー、問題提起、危険性の検証を中心としたチャンネルにはしない
- 無断侵入風、営業妨害風、所有物の破壊、騒音、強引ないたずらなど、視聴者が「本当にやってよいのか」と感じる題材を扱う
- 「友達の家を爆破してみた」のような、爆破・破壊を含む大げさで非常識な企画表現も使用できる
- 人を殺す内容は扱わない
- 実在する個人・企業を攻撃対象にせず、現実で危険行為や犯罪を再現するための具体的手順は記述しない
- 必要に応じて架空の人物・施設、撮影用セット、合意済みの出演者、小道具などを用い、ゲーム内企画として過激さを表現する
- 炎上系は他スタイルより伸びやすい
- 炎上系は他スタイルより炎上しやすい
- 炎上は再生数へ直接影響しない
- 炎上すると登録者数が5%減少する
- 炎上すると体力が20減少する
- 炎上を3回起こすとアカウントBANとなり、ゲームオーバー

### 11.2 チャンネル種類ごとの炎上確率【確定】

炎上判定は動画1本ごとではなく、1週間に1回だけ行う。週1本・週3本・週7本のどれを選んでも、週間炎上確率は変わらない。

| チャンネル種類 | 週間炎上確率 | チャンネル再生数倍率 |
|---|---:|---:|
| 王道系 | 0.1% | 1.0倍 |
| 特化系 | 0.1% | 1.0倍 |
| 炎上系 | 5.0% | 1.5倍 |
| アイドル系 | 0.1% | 1.0倍 |

炎上系は、ほかのチャンネル種類より週間炎上確率が50倍高い。

### 11.3 炎上発生時の処理【確定】

- その週の動画投稿、ランダムイベント、登録者増加を反映した後に炎上判定を行う
- 炎上時は、その時点の登録者数を5%減少させ、`floor(炎上前登録者数 × 0.95)` で炎上後の登録者数を求める
- 炎上時は体力を20減少させる
- 炎上回数を1増加させる
- 炎上自体は動画再生数を増減させない
- 炎上と週間ランダムイベントは独立して判定する
- 投稿やアルバイトなどの通常の体力消費に、炎上による体力20減少を追加する
- 炎上後に体力が0以下なら、病気判定を行わず死亡によるゲームオーバーとする
- 体力が残っている場合だけ、炎上後の体力を使って共通の体調不良を判定する

登録者5%減少後に1人未満の端数が発生した場合は、小数点以下を切り捨てる。

### 11.4 炎上回数とアカウントBAN【確定】

- 炎上回数はゲーム開始から累積する
- 1回目と2回目は通常の炎上ペナルティだけを適用する
- 3回目の炎上が発生した時点でアカウントBANとなり、ゲームオーバーにする
- ステージをクリアしても炎上回数をリセットしない
- 初期版では謝罪、休止、時間経過などによって炎上回数を減らす仕組みを設けない
- 3回目の炎上と体力0が同時に成立した場合、少なくともゲームオーバーであることは共通であり、画面上の主な終了理由はBANを優先する

### 11.5 バランス上の注意【確定値に対する分析】

炎上系の週間炎上確率5%で156週間を毎週独立判定すると、3回以上炎上する確率は約98.6%となる。そのため、炎上系は1.5倍の再生数メリットを持つ一方、3年間生き残ることが非常に難しい。

週間炎上確率を1%にした場合、156週間で3回以上炎上する確率は約20.6%となるが、これは将来のバランス調整案であり、現在の確定仕様ではない。現在は炎上系5.0%、その他0.1%を使用する。

## 12. 機能解放

### 12.1 コラボ【確定】

- 登録者50,000人へ一度でも到達するとコラボ機能を永続解放する
- コラボは週間メイン行動の1つ
- 金銭的な費用はなく、体力を10消費する
- コラボを選択した週は、投稿するすべての動画へ1.5倍のコラボ倍率を適用する
- クールダウンは実施週を含む2週間とし、第N週に実施した場合は次に第N+2週から選択できる
- 同じ週にアルバイト、休憩、企業案件は選択できない
- 初期版ではコラボ相手を選択・保存せず、相手選択は将来拡張とする

### 12.2 広告収益【確定】

- 登録者3,000人到達で広告収益機能を解放する
- 週の途中で一度でも3,000人へ到達した場合、その後同じ週のSNS批判や炎上で3,000人未満になっても解放する
- 広告収益が発生するのは、解放条件を達成した翌週から
- 一度解放した後は、登録者が3,000人未満へ減っても解放状態を維持する
- 広告収益は対象再生数1回あたり0.2円
- 週間広告収益は `floor(対象再生数 × 0.2円)` で計算する
- ランダムイベントによる再生数補正を広告収益にも反映する
- 過去動画からの継続的な広告収益は初期版に実装しない

### 12.3 企業案件【確定】

- 登録者100,000人へ一度でも到達すると企業案件を永続解放する
- 企業案件は週間メイン行動の1つで、同じ週にアルバイト、休憩、コラボは選択できない
- 金銭的な費用はなく、体力を5消費する
- クールダウンは実施週を含む4週間とし、第N週に実施した場合は次に第N+4週から選択できる
- 報酬区分にはその週の開始時点の登録者数を使用する

| 週開始時の登録者数 | 報酬 |
|---:|---:|
| 100,000〜299,999人 | 100,000円 |
| 300,000〜499,999人 | 200,000円 |
| 500,000〜999,999人 | 400,000円 |
| 1,000,000〜4,999,999人 | 800,000円 |
| 5,000,000〜9,999,999人 | 1,200,000円 |
| 10,000,000人以上 | 2,000,000円 |

コラボと企業案件は、週の途中で解放条件へ一度でも到達したら永続解放する。メイン行動は週進行前に選択するため、実際に選択できるのは到達翌週からとなる。

## 15. ゲームオーバーとクリア

### 15.1 ゲームオーバー条件【確定】

- 各ステージの156週間以内に目標登録者数へ到達できない

ステージ期限切れの場合は、期限最終週の動画、登録者、収益、企画消費などを通常どおり確定する。その最終結果でも目標未達だった場合にゲームオーバーとする。終了した人生の値は次の人生へ引き継がない。

## 21. まとめ
